# MtrScope

**Continuous per-hop network probing (MTR), PING, TCP port scan, DNS lookup — on Android.**

A professional network diagnostic tool for engineers: live MTR/PING tracing with rDNS + Geo/ASN per hop, route map, health dashboards, batch tabs, history, export & share, and a configurable home-screen widget.

- **Status:** Production (Google Play)
- **Platform:** Android 8.0+ (minSdk 26)
- **License:** Proprietary — all rights reserved. This repository is for distribution and documentation only; **source code is not published.**

---

## Features

| Area | Details |
|---|---|
| Tracing | MTR & PING, continuous per-cycle probing, live streaming table, per-hop sparklines |
| Info per hop | rDNS hostname, Geo country + ASN (ip-api.com, disk-cached 7d) |
| Health | Loss / Avg / Jitter (RFC 6312) health bar, trend chart, trace diff |
| Multi-target | Tabs per host, comma-separated batch, batch summary compare |
| Route map | OpenStreetMap great-circle route with direction arrows |
| MORE tools | DNS Lookup (A/AAAA/CNAME/NS/MX/TXT/RDNS/WHOIS/ALL), TCP Port Scan, Net Info |
| History | Saved traces: search, compare, favourites, replay |
| Export | Copy / share as text, CSV, JSON or styled PNG |
| Theme | Follow-system / Light / Dark / Auto (06:00–18:00) |
| Widget | Home-screen widget: tap to type host, ▶ MTR / ▶ PING direct run, resizable |
| IPv6 | Dual-stack aware, IPv6 targets supported |
